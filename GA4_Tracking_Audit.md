## Event schema

Every custom event uses page_path, page_title, page_location, page_name, page_type; project_id and project_name are included when relevant; photo albums include album_id. No screen_view or invented screen_class values.

| Event | Additional parameters | Trigger |
|---|---|---|
| page_view | page_referrer | Initial route commit and real route changes, including back/forward; same canonical path deduplicated |
| section_view | section_id, section_name, visible_percent=50, visibility_ms=1000 | Qualified homepage section exposure |
| project_open | view_type=route/modal, detail_id, detail_name or modal_type | Case-study/detail visit; project media modal open |
| project_navigation | from_project_id, to_page_path, to_project_id | Leave a project for another real page |
| portfolio_filter | filter_name=status, filter_value | All/Ongoing/Completed filters on catalogue and log |
| resume_download | file_name=resume.pdf, file_extension=pdf, link_placement | Resume link click: measures download/open intent, not confirmed completion |
| contact_click | contact_method=email/phone/linkedin, link_placement | Contact link click; no actual address or phone number |
| outbound_click | link_domain, link_url=origin only, outbound=true | External HTTP(S) link click |
| section_navigation | navigation_type=anchor | Anchor on same canonical page |
| modal_view | modal_type, view_type=modal | Open lightbox; never a page visit |
| modal_interaction | modal_type, action=close/navigate | Modal controls |
| toolkit_select | toolkit_id, toolkit_name | Current homepage skills category tab |
| toolkit_expand | toolkit_name, expanded | Toolkit toggle |
| hero_interaction | action=camera_pose | Hero camera interaction |
| playground_interaction | action=move/jump/scene_change/move_to_destination/advance_scene, scene_id | Intentional playground actions, throttled to one per action/scene per two seconds |

## GA4 administration

Automatic history page views, outbound clicks, and file downloads disabled in the existing Alexander Chen Works Google tag's automatic event detection; both destinations preserved. Automatic scroll/video/form settings left unchanged. send_page_view=false is set globally before tag initialization and on both destination configs. Manual events explicitly target both existing destination IDs once; separate properties receiving one copy each are not duplicate visits within a property. No additional tag or property created.

Recommended event-scoped custom dimensions: Page name (page_name), Page type (page_type), Section ID (section_id), Section name (section_name), Project ID (project_id), Project name (project_name), Detail name (detail_name), View type (view_type), Modal type (modal_type), Interaction action (action), Scene ID (scene_id), Filter value (filter_value), Contact method (contact_method), Link placement (link_placement). Use built-in Page path and screen class, Page title and screen name, Page location, Page referrer, Event name, Link domain where available. Do not register page_path merely to populate app dimensions.

Mark resume_download and contact_click as key events if these are your desired lead-intent conversions. These indicate intent, not a completed email/phone conversation or successful PDF transfer.

Reports: Pages and screens with Page title and screen name or Page path and screen class + Views, Active users, Average engagement time, Key events. Exploration: section_view filtered table with Section name + Event count and Total users. Project interest: project_open by Project name and View type. Contact/resume: key events by Page title and Contact method. Filters: catalogue/log portfolio_filter by Filter value.

Custom definitions apply prospectively and can take 24–48 hours to appear in standard reports. Historical fragmented data is not rewritten.

## Privacy, consent, development

No consent grants added or changed; existing Consent Mode commands are retained. Unknown hashes are never transmitted. Query strings, emails, phone destinations, external paths, and arbitrary form inputs are not sent by custom events. First referrer is external origin only; later referrer is the previous canonical portfolio page. localhost, IP hosts, and preview hosts do not load GA4. Do Not Track and the existing ga-disable flag are respected. ?analytics_debug=1 enables DebugView and labels traffic_type=developer; it is stripped from reported paths. Create/activate a developer traffic filter only after testing it, to avoid hiding real users.
